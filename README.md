# Subgen

*Video subtitle generator: subtitles in the original language via Whisper (auto-detected), translation into ~50 languages, muxed into MKV. UI in ~50 languages. **English: [README.en.md](README.en.md).***

Subgen — программа для Windows, которая делает к видео субтитры на языке оригинала (распознаёт речь моделью Whisper, язык определяется сам) и перевод на выбранный язык, а затем вшивает обе дорожки в MKV-файл. Подходит для изучения любого языка: английский сериал с русским переводом, японское аниме с английским, немецкий фильм с украинским и т. д. Перетащили серии или папку — получили MKV с дорожками, например, «Japanese (Whisper)» и «Русский».

Интерфейс — на ~50 языках: язык выбирается при установке (по умолчанию — язык Windows, если он есть в списке, иначе английский) и меняется на вкладке «Модели» («Язык интерфейса», применяется после перезапуска). Русский и английский переведены вручную, остальные языки — машинным переводом, поэтому формулировки могут быть неточными.

![Вкладка «Генерация»](docs/tab-generation.png)

## Возможности

- **Субтитры на языке оригинала по звуку.** Whisper сам определяет язык речи (в журнале видно, какой и с какой уверенностью). Если определяет неверно, выберите «Язык оригинала» вручную. По умолчанию субтитры всегда генерируются — даже если в файле уже есть свои (они часто сделаны до дубляжа и не совпадают с голосами). Если вшитые субтитры подходят, включите «Использовать вшитые субтитры на языке оригинала (без генерации)»: тогда переводятся они, а новая дорожка оригинала не добавляется.
- **Перевод на любой из ~50 языков** («Перевести на:», выбор запоминается): Google Переводчик (онлайн) или офлайн-модели, работающие без интернета. Если язык оригинала совпадает с языком перевода, перевод не делается.
- **Бережная работа с файлом.** Исходные дорожки (видео, звук, чужие субтитры, шрифты) не удаляются. Свои дорожки программа помечает тегом `SUBGEN=1` (и `SUBGEN_ROLE=orig` / `trans` — оригинал или перевод), и при повторной обработке заменяет только их — с любой парой языков. Дорожка оригинала программы становится основной (по умолчанию), остальные субтитры — нет. Файлы, обработанные прежними версиями (без `SUBGEN_ROLE`), тоже понимаются: английская дорожка программы считается оригиналом, остальные — переводом. Результат сначала пишется во временный файл, проверяется `ffprobe` (длительность и число дорожек), и только потом оригинал уходит в Корзину.
- **Менеджер дорожек:** название, язык, флаг «по умолчанию», удаление звуковых дорожек и субтитров у любого видео.
- **Менеджер моделей:** выбор, скачивание с прогрессом и удаление моделей Whisper и переводчиков.
- Очередь из многих серий, прогресс и оценка оставшегося времени, журнал. Работает на видеокарте NVIDIA (CUDA), а без неё — на процессоре.

## Требования

- Windows 10 или 11 (64-бит).
- Видеокарта NVIDIA — желательно, но не обязательно (без неё распознавание идёт на процессоре, в разы медленнее). Достаточно обычного драйвера, CUDA Toolkit не нужен.
- Место на диске: около 2 ГБ под программу и библиотеки + модели (рекомендуемая Whisper large-v3-turbo — 1,5 ГБ).
- Интернет — для установки, скачивания моделей и перевода через Google.

## Установка

1. Скачайте проект: зелёная кнопка **Code → Download ZIP** на GitHub (распакуйте в любую папку) или
   ```
   git clone https://github.com/Laith-UE5/Subgen.git
   ```
2. Запустите **`install.cmd`** двойным щелчком, выберите язык интерфейса (номер или код из списка; Enter — язык Windows) и дождитесь надписи «Готово». Без вопроса: `powershell -ExecutionPolicy Bypass -File install.ps1 -Lang ru`.

Что делает установщик (его можно запускать повторно — уже установленное пропускается):

- ставит [uv](https://docs.astral.sh/uv/) — менеджер Python (через `winget`, а если не вышло — официальным скриптом astral.sh);
- ставит ffmpeg через `winget` (пакет `Gyan.FFmpeg`), если его ещё нет;
- скачивает Python 3.12 под управлением uv и создаёт окружение в `%LOCALAPPDATA%\Subgen\venv`;
- устанавливает зависимости из `requirements.txt` (около 1,5 ГБ, в основном библиотеки CUDA);
- создаёт ярлыки **Subgen** на рабочем столе и в меню «Пуск».

Где что лежит:

| Что | Где |
|---|---|
| Код программы | папка, куда вы распаковали проект (ярлыки ссылаются на неё) |
| Окружение Python | `%LOCALAPPDATA%\Subgen\venv` |
| Модели | `%LOCALAPPDATA%\Subgen\models` |
| Настройки (модели, язык перевода, язык интерфейса `ui_lang`) | `%LOCALAPPDATA%\Subgen\settings.json` |

Если переместили папку с программой — запустите `install.cmd` ещё раз, ярлыки обновятся. Путь может содержать пробелы и кириллицу.

## Использование

1. Откройте **Subgen** (или сразу перетащите видео/папку на ярлык — обработка начнётся сама).
2. Перетащите серии или папку в окно либо нажмите «Добавить файлы» / «Добавить папку».
3. Проверьте «Язык оригинала» (обычно «Автоопределение») и «Перевести на:» (по умолчанию Russian).
4. Нажмите **Старт**. При первом запуске скачается выбранная модель Whisper.

Результат — `имя.mkv` рядом с исходником (MP4, AVI и др. превращаются в MKV), оригинал — в Корзине. Отдельные `.srt` рядом не создаются — субтитры только вшиваются в видео (если вшить не удалось, например `имя.ja.srt` и `имя.ru.srt` сохраняются рядом, чтобы работа не пропала). Если путь к файлу длиннее 250 символов, Корзина такие файлы молча удаляет, поэтому оригинал не удаляется, а переименовывается в `имя.original.ext`.

**Дорожки и языки.** Дорожка оригинала называется «<Язык по-английски> (Whisper)», например «Japanese (Whisper)», перевод — самоназванием языка: «Русский», «Deutsch», «日本語». Язык дорожки записывается кодом ISO 639-2 (`eng`, `jpn`, `rus`, `ger`…), так плееры сами показывают нужный язык. Если в файле несколько звуковых дорожек, распознаётся дорожка на выбранном языке оригинала, а при автоопределении — дорожка «по умолчанию».

**Вшитые субтитры.** При «Автоопределении» берётся первая текстовая дорожка субтитров (не созданная программой), а язык — из её тега. Если язык у дорожки не указан, программа выдаст ошибку и попросит выбрать язык оригинала явно. Если язык выбран, берётся дорожка с этим языком, а если такой нет — субтитры генерируются Whisper'ом.

Консольный режим:

```
subgen.cmd "D:\Аниме\Сезон 1" [--source auto|ja|en|...] [--target ru|en|de|...] [--embedded] [--model large-v3-turbo] [--translator nllb-1.3b]
```

`--source` — язык оригинала (по умолчанию `auto`, определяет Whisper), `--target` — язык перевода (по умолчанию — из настроек), коды ISO 639-1: `en`, `ru`, `ja`, `de`, `zh`… Старый флаг `--embedded-en` по-прежнему работает как `--embedded`.

## Выбор моделей

Вкладка **«Модели»**: выбранная модель запоминается, скачать её можно заранее или она скачается при первой обработке.

![Вкладка «Модели»](docs/tab-models.png)

**Whisper (распознавание речи):**

| Модель | Размер | Когда брать |
|---|---|---|
| large-v3-turbo | 1,5 ГБ | **рекомендуется**: с видеокартой NVIDIA быстро и точно |
| large-v3 / large-v2 | 3 ГБ | максимальная точность, в несколько раз медленнее turbo |
| medium / small | 1,5 ГБ / 485 МБ | компьютер без видеокарты |
| tiny / base | 75 / 145 МБ | проверить, что всё работает; качество низкое |

Модели с `.en` понимают только английский — чуть точнее на английской речи для размеров tiny…medium. С ними язык оригинала считается английским; если выбрать другой язык оригинала, обработка остановится с объяснением.

**Перевод:**

| Переводчик | Размер | Комментарий |
|---|---|---|
| Google Переводчик | — | по умолчанию; нужен интернет, через некоторые VPN не работает |
| OPUS-MT en→ru | 80 МБ | маленький и очень быстрый, качество приличное; **только с английского на русский** — для других пар недоступен (если всё же выбран, дорожка перевода не добавляется, в журнале предупреждение) |
| NLLB-200 600M | 600 МБ | хорошее качество |
| NLLB-200 1.3B | 1,3 ГБ | **лучший офлайн-вариант** по нашим тестам |
| MADLAD-400 3B | 2,8 ГБ | крупная модель, нужна видеокарта (на процессоре медленно) |

Какой переводчик сработал, видно в журнале. Модели NLLB распространяются Meta по лицензии CC-BY-NC 4.0 (только некоммерческое использование).

**Про VPN.** Google Переводчик может быть недоступен через VPN. Тогда дорожка перевода не добавляется, а в журнале появляется предупреждение; дорожка оригинала всё равно вшивается. Выключите VPN или выберите офлайн-переводчик и обработайте файл ещё раз — дорожки программы заменятся. Если в файле уже был перевод программы на тот же язык, при сбое перевода он сохраняется.

## Менеджер дорожек

Вкладка **«Дорожки»**: откройте или перетащите видео — появится список всех потоков (номер, тип, кодек, язык, название, флаг «по умолчанию»). Можно переименовать дорожку, сменить язык (трёхбуквенный код: `eng`, `rus`, `jpn`), включить или выключить «по умолчанию», удалить звуковые дорожки и субтитры. Видеодорожки удалить нельзя. После «Применить» файл пересобирается так же безопасно (временный файл → проверка → оригинал в Корзину), и показывается список дорожек нового файла. Дорожки, созданные программой, отмечены «Subgen».

![Вкладка «Дорожки»](docs/tab-tracks.png)

## Решение проблем

- **«Видеокарта (CUDA) не сработала»** — программа сама переключится на процессор. Обновите драйвер NVIDIA; убедитесь, что `install.cmd` завершился без ошибок.
- **«Не найден ffmpeg»** — выполните `winget install --id Gyan.FFmpeg -e` или снова `install.cmd`.
- **«ПЕРЕВОД НЕ УДАЛСЯ»** — см. «Про VPN» выше.
- **«рядом уже есть файл имя.mkv»** — при обработке MP4/AVI рядом уже лежит MKV с тем же именем; программа его не перезаписывает.
- **Модель не скачивается** — проверьте доступ к huggingface.co; прерванная загрузка докачивается при следующей попытке.
- **Ошибка при обработке** — оригинал не трогается; подробности в «Журнале» внизу вкладки «Генерация».

## Удаление

Запустите **`uninstall.cmd`**: удаляются ярлыки и окружение Python, затем программа спросит, удалять ли модели и настройки (`%LOCALAPPDATA%\Subgen`). После этого можно удалить папку с программой. uv и ffmpeg остаются (их можно удалить через `winget uninstall`).

## Для разработчиков

- `subgen/core.py` — обработка (Whisper, перевод, вшивание), `subgen/models.py` — каталог и загрузка моделей, `subgen/tracks.py` — менеджер дорожек, `subgen/gui.py` — окно.
- Тексты интерфейса — `subgen/locales/<код>.json`, функция `t()` в `subgen/i18n.py` (нет строки — берётся английская). `en.json` и `ru.json` правятся вручную; остальные пересоздаются из `en.json`: `python tools/gen_locales.py --force [--only de,ja] [--engine google|nllb-1.3b]`, проверка — `python tools/gen_locales.py --check`.
- Быстрая проверка вшивания и менеджера дорожек без моделей: `%LOCALAPPDATA%\Subgen\venv\Scripts\python.exe tests\test_mux.py`.
- Иконка рисуется скриптом `assets/make_icon.py` (Pillow).
